# 📚 Aulas de C e C++

Bem-vindo ao repositório **Aulas-C**!

Este repositório foi criado para organizar, armazenar e acompanhar as atividades práticas desenvolvidas pelos alunos durante as aulas de programação nas linguagens **C e C++**.

## 🎯 Objetivo

O objetivo deste repositório é incentivar o aprendizado de programação e a utilização de ferramentas de versionamento de código, como Git e GitHub.

Os alunos poderão enviar suas atividades, acompanhar as correções e aprender a trabalhar com Pull Requests.

## 💻 Linguagens utilizadas

- **C:** fundamentos de programação, variáveis, operadores, estruturas condicionais, laços de repetição e funções.
- **C++:** fundamentos de programação, entrada e saída de dados, estruturas de controle, funções e introdução à programação orientada a objetos.

## 📁 Organização do repositório

As atividades serão organizadas em pastas, conforme a linguagem e o conteúdo estudado.

```text
Aulas-C/
│
├── Atividades-C/
│   ├── Atividade-01/
│   └── Atividade-02/
│
├── Atividades-CPP/
│   ├── Atividade-01/
│   └── Atividade-02/
│
└── README.md
```

Cada aluno deverá identificar seus arquivos com seu nome ou utilizar uma pasta individual, conforme a orientação do professor.

## 🚨 Regras de envio — IMPORTANTE

**A branch `main` é protegida.**

Não é permitido enviar atividades diretamente para a `main`.

Todos os alunos deverão realizar suas alterações em uma branch separada e solicitar a inclusão dos arquivos por meio de um **Pull Request (PR)**.

### Regras obrigatórias

1. Não realizar `push` diretamente para a `main`.
2. Criar uma branch para desenvolver a atividade.
3. Enviar apenas arquivos relacionados à atividade solicitada.
4. Identificar corretamente o aluno e a atividade.
5. Abrir um Pull Request direcionado à `main`.
6. Aguardar a análise e aprovação do professor.

**Somente após a aprovação e o merge do Pull Request a atividade será incorporada à branch principal.**

## 🚀 Como enviar sua atividade

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Entre na pasta

```bash
cd Aulas-C
```

### 3. Crie sua branch

```bash
git switch -c atividade-nome-aluno
```

### 4. Adicione os arquivos

```bash
git add .
```

### 5. Registre suas alterações

```bash
git commit -m "Entrega da atividade 01"
```

### 6. Envie sua branch ao GitHub

```bash
git push -u origin atividade-nome-aluno
```

### 7. Abra um Pull Request

No GitHub:

1. Acesse o repositório.
2. Clique em **Compare & pull request**.
3. Confira se a branch de destino é `main`.
4. Informe seu nome e a atividade realizada.
5. Clique em **Create pull request**.
6. Aguarde a revisão do professor.

## 📝 Avaliação das atividades

As atividades poderão ser analisadas considerando:

- Funcionamento correto do código.
- Organização dos arquivos.
- Utilização dos conceitos apresentados em aula.
- Clareza e legibilidade do código.
- Cumprimento das instruções de entrega.

Caso sejam necessárias correções, o aluno poderá atualizar sua branch e enviar novos commits para o mesmo Pull Request.
